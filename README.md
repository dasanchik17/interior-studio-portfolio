# Студия дизайна интерьера «Метрика» — Портфолио

Адаптивный сайт-портфолио для студии дизайна интерьера. Проект выполнен в рамках обучения frontend-разработке с использованием семантической вёрстки, современного CSS (Flexbox, Grid) и методологии БЭМ.

## 📌 Функциональность

- Главная страница с секциями:
  - Шапка (логотип и навигация)
  - О нас
  - Наши проекты
  - Услуги
  - Контакты (подвал)
- Полная адаптивность под все устройства (от 320px)
- Плавные hover-эффекты для карточек и кнопок
- Сетки с использованием CSS Grid и Flexbox

## 🛠 Технологии

- HTML5 (семантические теги: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>` и др.)
- CSS3 (переменные, медиазапросы, анимации)
- БЭМ-именование классов
- Git / GitHub (работа с ветками, Conventional Commits)

🌿 Ветвление и коммиты
Проект разрабатывался с использованием Git-флоу:

main — стабильная версия (только базовый коммит)

develop — ветка разработки, куда вливались все фичи

Ветки фич:

feature/header
feature/about-section
feature/projects-section
feature/services-section
feature/footer-section
feature/final-polish (адаптивность и финальные правки)

Коммиты оформлялись по Conventional Commits:

feat(scope): — новая функциональность
style(scope): — стили и оформление
assets(scope): — добавление изображений
fix(scope): — исправления
refactor(scope): — рефакторинг

Примеры:

text
feat(header): добавить HTML-разметку с логотипом и навигацией
style(header): добавить основные стили для заголовка и навигации
assets(header): добавить изображение логотипа
feat(responsive): добавить полную адаптивность и финальные правки
